# Cake 4 All — Order Management Dashboard

A modern, cloud-based administrative control panel built to manage custom cake orders, client histories, and live product pricing maps.

## 🛠️ Tech Stack
* **Frontend:** React, Tailwind CSS, Lucide Icons
* **Database & Cloud Core:** Supabase Realtime Storage

## ✨ Implemented Core Features
* **Cloud Pricing Sync:** Live base rate management panel with direct inline rename and delete hooks.
* **Order Automation Panel:** Full-spectrum order creation interface featuring auto-calculating price matrices.
* **Responsive Sidebar UI:** Adaptive workspace layout engineered smoothly for mobile or desktop administration.
